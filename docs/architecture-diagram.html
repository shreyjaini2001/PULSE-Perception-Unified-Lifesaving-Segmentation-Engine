Architecture

Top-to-bottom MASCAL relay flow

Layer
01

Medic Input

Lead medic starts a scan, points the device at one casualty, and captures a short head-to-toe sweep.

Operator Start / Stop scan One victim at a time
Layer
02

Edge Capture

The edge node owns the camera, buffers live frames, and keeps the current scene available for scan and broadcast flows.

OpenCV capture Local GPU Offline-first
Layer
03

Perception

Person detection, face re-ID, wound localization, blood pooling, rPPG, and transcript capture run on-device against the live feed.

YOLOv8 pose Grounding DINO SAM 2 / SAM 3 InsightFace Whisper
Layer
04

Medical Reasoning

The scan engine aggregates findings into MARCH, SALT, priority, timers, and MIST-style handoff context.

MARCH SALT P1-P5 queue MIST
Layer
05

Scan Record

A frozen casualty record is created with wound tags, body locations, face crop, frame crop, transcript, and audit metadata.

Scan record Keywords Face thumbnail Audit trail
Layer
06

Relay and UI

The edge node broadcasts snapshots and scan events to the receiver dashboard so follow-on medics can treat by priority.

HTTP dashboard WebSocket stream Shared queue
